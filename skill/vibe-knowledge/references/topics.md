# 选题

选题是最重要的一步。

## 两种已验证的结构

**A. 演进史型**（《运气的形状》= GPT 进化史）
一条清晰的 A → B → C → 终局 演进线，天然分幕，有"一路升级"的爽感。每一幕找一个数学 / 物理隐喻画出来。适合科普 / 技术类，结尾用「片名 + 英文」。

**B. 生活切口型**（《月老的算法》《何时该停下》）——传播性更强，优先推荐
> 生活化切口 + 一个硬核模型 + 权威背书（诺奖 / 著名定理）+ 反直觉结论 + 现实应用

- 《月老的算法》：相亲 → Gale-Shapley 稳定匹配 → 诺贝尔经济学奖 → 谁先开口谁占优 → 分医院、分学校
- 《何时该停下》：找对象 → 最优停止 / 秘书问题 → 1/e → 先看 37% 再出手；仍有 63% 等不到 → 租房、招人、24 岁

适合情感 / 生活类，结尾用「二选一」。

## 评判标准

1. 有清晰的叙事线（演进或冲突 → 揭晓）
2. **每一段都能找到可视化隐喻**，最好能用粒子、柱子、曲线、网格、分形画出来
3. 大众熟悉，原理神秘（人人听过，没几个人真懂）
4. 有一个能当标题钩子的数字或反直觉结论（37%、24 岁、谁先开口）
5. 结尾能升华成一句金句，或落到一个二选一问题
