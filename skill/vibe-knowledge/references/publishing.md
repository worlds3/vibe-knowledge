# 发布文案

## 标题（≤30 字，给 2–3 个选项）

- 系列统一格式（首推）：`Vibe知识大赏 | 《片名》`
- 钩子型：把反直觉结论或数字放进标题，例如「遇到第几个人，就该停下？数学说是 37%」
- 场景型：「恋爱、租房、找工作，都藏着一个 37% 法则」

## 描述（参考用户发过的样例格式）

```
Vibe知识大赏 | 《片名》<一句和观众有关的钩子问题>

<冲突：直觉的两种失败，一两句>
<答案：模型给出的方法，一两句>
<为什么：可视化证明的结论，带数字>
<反转 / 另一面，一句>
<落到生活的一个具体结论>

<结尾问题>

本视频由 Claude 制作

#vibe知识大赏 #claude5.5 #opus5.5 #<模型名> #<领域> #<生活场景> #ai新星计划
```

- 话题 8–10 个：系列标签 + 模型 / 工具标签 + 知识点 + 领域 + 生活场景
- 不要编造播放量、奖项、引用

## 封面

挑一帧数字或结论最亮的画面（例如峰值「37%」亮起、「24.3 岁」出现），告诉用户具体时间点。

## 置顶评论

自己先抛一个轻松的问题带互动，例如"我已经过了 24 岁，是不是该停了😂"。
