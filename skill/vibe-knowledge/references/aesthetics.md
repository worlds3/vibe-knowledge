# 审美要求（来自用户，优先级最高）

这是用户对「有意思的知识科普短视频」的理解。不是 100% 硬性，但默认都要做到。

## 五条核心

1. **开头要抓眼球，有视觉锚点。** 第一秒就要有炫的画面，或者一个和题目强相关的物件，让眼睛有落脚点。
   - 《运气的形状》：开场直接跑出一个骰子动画
   - 讲情感：画面里一部手机，模拟微信消息一条条弹出
   - 《何时该停下》：10 个人像气泡环绕手机 → 被吸进屏幕 → 交友卡片一张张被划走
   - 也可以是线条、粒子构成的图形，但必须和主题有关

2. **第一句文案和观众相关。** 让观众代入，不要一上来就讲术语、讲历史。
   - 好：「如果你这辈子，会认真遇见 10 个人」
   - 坏：「1960 年代，数学家提出了秘书问题」

3. **有节奏感。** 音乐、文案、画面要配得上：段落切在 BGM 的能量突变点，核心揭晓放在爆发处，反思放在安静段；画面上的光晕、脉冲跟着音频能量走（模板的 `env(t)` / `kick(t)`）。

4. **抛一个问题给观众。** 开头抛一次（钩子），结尾再抛一次（互动）。

5. **转场丝滑，不要硬切。** 镜头推进到某个细节 → 细节铺满画面 → 展开成下一个场景。转场要短而干净，前后两个画面不要长时间叠在一起（交叠 ≤ 0.5 秒）。

## 用户反馈过的修改（必须遵守）

- **不要顶部进度条，也不要常驻的「Vibe 知识大赏 +《片名》」页眉**：影响整体观感。左上角的章节小标签（`01 —— 章节名`）可以保留。
- **默认横屏 1920×1080**，导出 **4K（3840×2160）60fps**：抖音帧率上限 60，所以用分辨率换清晰度。
- **不要片尾的「片名 + 评论区见」那种落幅**。结尾按题材二选一：
  - **情感 / 生活类**（爱情、选择、人生）→ **二选一结尾**：抛出一个问题，两个选项，选择器在两者之间丝滑来回切换（带拉伸、变色、粒子被吸过去），切换周期性循环。很多观众会录屏当朋友圈实况，所以最后几秒要能无缝循环、每一帧都好看。模板组件 `endingChoice`。
  - **科普 / 技术类**（神经网络、AI 绘画进化史……）→ **片名 + 英文结尾**：中文大标题逐字浮现 + 细线 + 英文大写宽字距（字距从宽收紧）+ 一句英文斜体 tagline。**不要「评论区见」**，靠英文和留白营造高级感。模板组件 `endingTitle`。

- **文案说什么，画面就出现什么（尤其是第一幕）**。《从噪声到世界》第一版开头字幕说「你最近刷到的那些 AI 图」，画面却只有一台雪花电视，观众会觉得空等了很久才对上。改成：先弹出一墙 AI 图卡片（美女、二次元、赛博朋克、风景……带话题标签和点赞数，像刷信息流）→ 字幕说「诞生之前」时卡片反向去噪成雪花 → 说「一屏雪花」时电视弹入、雪花被吸进屏幕。写分镜时逐句检查：这一句字幕出现的那一刻，画面上是不是就在演这句话。

## 视觉基调（模板默认）

- 深色底（#0a0c14 → #05060a），背后缓慢漂移的彩色光团 + 星尘，胶片颗粒 + 暗角
- 金色 `#ffcf6e` = 被选中 / 答案；玫红 `#ff5d7a` = 情绪 / 失败 / 心动；冰蓝 `#7fb3ff` = 观察 / 理性；灰蓝 = 被淘汰
- 中文：Noto Sans SC（字幕）、Noto Serif SC（大标题、大数字）；英文：Cormorant Garamond
- 字幕底部居中，逐字浮现，带柔和暗场托底
- 每段换一个背景色调（`TINTS`），帮助观众感知段落变化

## 参考项目的教训

`vibe-gpt-evolution`（《运气的形状》）的实现方式值得参考（Canvas + 数学驱动粒子），但画面偏单调：每幕只是一个居中的几何图形加文字卡片、字幕和画面割裂、转场是淡入淡出。做新视频时避免这些。
