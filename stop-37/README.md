# 何时该停下 · 最优停止 / 37% 法则

Vibe 知识大赏横屏视频（1920×1080，约 130 秒），BGM 沿用 `vibe-gpt-evolution/bgm.mp4`。

## 运行

双击 `start.bat` 即可（会启动本地服务器并打开浏览器）。也可以手动：

```bash
python -m http.server 8737
```

浏览器打开 http://localhost:8737 。

- **播放**：空格 播放/暂停，← → 快退/快进 5 秒，F 全屏，Esc 回到面板
- **导出 MP4**：点面板上的「导出 MP4」，默认 120fps，逐帧离线渲染（不掉帧、音画严格同步），约 10 分钟，导出时保持标签页在前台
- URL 参数：`?t=50` 从第 50 秒开始，`?fps=60` 导出 60fps（更快、文件更小）

## 实现

纯 Canvas 2D，零运行时依赖（导出时按需加载 `mp4-muxer`）。所有画面都是 `render(t)` 的纯函数：播放时 `t = audio.currentTime`，导出时逐帧步进，再用 WebCodecs 编码 H.264 + AAC。BGM 的能量包络在页面加载时实时解析，让光晕、鼓点脉冲跟着音乐呼吸。
